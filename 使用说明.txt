==========================================
 一表通（OneSheet）v2.0 · 使用说明
==========================================

一表通用于：从多个文件中，把「标签:值」形式的表单数据批量抽取、
合并成一张汇总表；校对修改后，还能把汇总值反向写回各个 Excel 源文件
（另存到指定目录，不覆盖原件）。

支持格式：Excel（.xlsx / .xls / .xlsm）、Word（.docx）、PDF、CSV。
不同类型可以混在同一个文件列表里一起抽取。按文件真实格式识别
（WPS 另存的 xls 改名成 xlsx 也能正常读取）。

注意：
· 反向写入只支持 Excel；Word / PDF / CSV 是只读输入，不会被回填。
· 旧版 Word（.doc）不支持，请先另存为 .docx。
· 加密的 PDF / Word 暂不支持，请先移除密码。


【什么样的表能用】
------------------------------------------

例如：

  工资表
  姓名：  张三        性别：  男
  年龄：  34          部门：  采购部

· 标签与值可以左右相邻，也可以上下排列。
· 标签带不带冒号都可以，工具会自动去掉冒号。
· 版式复杂时，可用「AI 扫描表单」或「手动配对」指定。
· 参与抽取的多个文件，字段所在行列位置应基本一致。


------------------------------------------
一、快速上手（6 步）
------------------------------------------

  1. 导入：左侧点「导入文件」或「导入文件夹」；
     也可以把 Excel / Word / PDF / CSV 文件或文件夹直接拖进窗口。
     导入文件夹时会先弹出筛选设置：是否含子文件夹、每个文件夹最多几个、
     优先级（修改时间/文件名/大小）、文件大小范围和文件名正则，
     并实时预览将要导入的文件；设置会记住，下次自动沿用。
     （直接拖入文件夹不弹设置，按默认规则导入。）
  2. 预览：在左侧列表中双击文件，中间显示表格内容。
  3. 配字段：右侧用「扫描表单 / AI 扫描表单 / 手动配对」生成字段，
     并勾选要导出的项。
  4. 试抽：点「试抽当前文件」先检查这一个文件的取数是否正确。
  5. 抽取：确认无误后点「批量抽取」。
  6. 输出：校对结果后，点「导出 ▾」导出 xlsx 或 csv。

  常用功能在顶部菜单（文件 / 模板 / 数据 / 视图 / 帮助）里也有，
  并带快捷键，例如：Ctrl+O 导入文件、F5 批量抽取。


------------------------------------------
二、界面速览
------------------------------------------

  左 · 文件管理器：导入文件、搜索、勾选参与处理的文件。
      只有勾选的文件参与抽取和反向写入；支持全选 / 反选 / 全不选。
  中 · 预览：切换 sheet、查看单元格；手动配对时在这里点选。
  右 · 配置：模板、结果表、字段映射、主键等。
  下 · 汇总结果：多标签页结果（可直接编辑），同一行右侧是
      「试抽当前文件」「批量抽取」「反向写入」「导出 ▾」；
      「日志」页签点开才显示，下方是进度和取消按钮。

  同一功能通常有两个入口：菜单项和就近的面板按钮，用哪个都可以。


------------------------------------------
三、配置字段（三种方式）
------------------------------------------

  一个字段 = 汇总表的一列，由「标签（列名）」和「取值位置」组成。
  三种方式可混用，结果都进入「字段映射」表。

  · 在「字段映射」表里点选某一行，中间预览会自动滚动并高亮该字段
    对应的「标签」和「值」单元格，方便核对取值位置。
  · 表格里「值行 / 值列」可直接修改，改完「值预览」会同步更新。

  3.1 扫描表单（本地规则，最快）
  ----------------------------------------
  适合标签与值左右相邻、版式规整的表。
  点「扫描表单」后自动列出识别到的字段，默认全部勾选。

  3.2 AI 扫描表单（OpenAI 兼容接口，适合复杂版式）
  ----------------------------------------
  把当前预览的这一张 sheet 发给 AI 服务（默认 DeepSeek），让它推荐字段映射。

  · 首次使用会弹框要求输入 API Key，之后自动记住。
  · 随时可在菜单「数据 → AI 接口设置（OpenAI 兼容）…」填写、修改或查看
    Key、API 地址、模型、视觉模型：Key 默认密码显示，勾选「显示明文」即可
    查看；留空并确定可清除对应项。
  · 默认接口为 DeepSeek（地址 https://api.deepseek.com，模型 deepseek-chat）。
    也可换成任何兼容 OpenAI Chat Completions 协议的服务（OpenAI、通义千问、
    Kimi、本地 Ollama / LM Studio 等）：地址填基础地址（如
    https://api.openai.com/v1）或完整的 …/chat/completions 端点均可。
  · 环境变量优先于本地设置：
      DEEPSEEK_API_KEY 或 OPENAI_API_KEY  → API Key
      OPENAI_BASE_URL                      → API 地址
      OPENAI_MODEL                         → 模型
      OPENAI_VISION_MODEL                  → 视觉模型（扫描件 PDF 用）
  · 需要联网，且所用服务的账户有可用额度。
  · 能处理三类版式：
      ① 标签:值相邻的表单；
      ② 横向表格：表头各格是列标签，下面每行数据依次编号为
         「项目名称1」「项目名称2」…；
      ③ 纵向指标表：指标名称 / 计量单位 / 代码 / 数量，
         取「数量」列的值。
  · 会自动丢弃「有标签、没值」的项（空列、空数据行）。
  · 只发送当前 sheet，最多前 200 行、前 40 列，超大表可能漏字段。
  · 每次调用都记录在 data/logs/ai_scan.log，便于排查。
  · AI 给的是建议；不准确时仍可手动改位置或手动配对。

  3.3 手动配对（最准）
  ----------------------------------------
  适合自动识别不准、版式不规整的表。

  1. 点「手动配对」，状态栏提示点击标签。
  2. 在预览中点击「标签」单元格（如「姓名」）。
  3. 再点击它对应的「值」单元格（如「张三」）。
  4. 字段自动加入并勾选，继续点下一组。
  5. 再点一次「手动配对」结束。

  注意：手动配对按位置读取——点的是第几行第几列，之后每个文件都读
  该位置；同一个「值位置」不能被两个字段占用。


------------------------------------------
四、字段映射表
------------------------------------------

  字段会显示在「字段映射」表中：

    导出      勾选表示导出该列
    标签      输出列名，可直接修改
    值行      取值的行号（从 1 开始数）
    值列      取值的列号（从 1 开始数）
    值预览    按值行/值列实时读出的值（只读）

· 「添加文件名」按钮：添加一列「文件名」。这一列不读取单元格，而是从文件名里
  提取汉字（英文、数字、标点自动去掉）；文件名里没有汉字时，改用文件所在
  文件夹名。例：X企业2024.xlsx → 企业；
  采购部/2024.xlsx → 采购部。
  这一列用于把「对象名」（公司名、部门名等）带进汇总表；反向写入时不会
  写回源文件（它没有对应的单元格位置）。
· 自动扫描配错时，先看「值预览」是否正确；不对就直接改「值行/值列」。
  例：企业名称实际在第 3 列，扫描配成了第 2 列，把「值列」改成 3 即可。
· 字段顺序就是汇总表的列顺序。用「上移 / 下移」或拖动整行调整。
· 「添加字段」手动加一行；「删除选中」可一次删除多行
  （Ctrl 多选、Shift 连选）；「清空」删除全部字段（会先确认）。
· 「全选 / 反选 / 全不选」只控制勾选，不删除字段。
· 「主键字段」用于反向写入时识别「这一行对应哪个文件」。设置后，
  该字段会自动勾选导出，反向写入的匹配字段也默认只勾它。
· 标签重名会自动加数字后缀（如 项目名称2），只影响显示名，不影响取值。


------------------------------------------
五、批量抽取与导出
------------------------------------------

  1. 在左侧勾选要处理的文件（默认全选）；也可直接拖入文件/文件夹。
  2. 确认每个结果表的「sheet 关键字」：
       留空 = 使用第一个 sheet；
       填写 = 使用名称包含该关键字的第一个 sheet。

     各类文件的 sheet 命名（便于写关键字）：
       Excel   原工作表名
       Word    每个表格按顺序为「表1」「表2」…；段落为「正文」
               （「姓名：张三」这类段落会拆成标签/值两列）
       PDF     文字页的表格为「表1」「表2」…；
               无表格时按版式为「正文」；扫描件为「扫描」
       CSV     固定为「CSV」
     PDF 同一张表跨页时，各页会按页序自动拼成一个 sheet（表N / 正文 / 扫描），
     列数按最宽的一页补齐。整篇共用一套行列位置，所以 AI 扫描、试抽和批量
     抽取都能覆盖全部页面，不同页数的同类 PDF 也能用同一个模板。
     模板里的 sheet 关键字对同一格式的所有文件都适用；不同格式混抽时，
     建议按格式分别建结果表，或用留空关键字取第一个 sheet。
  3. 可先点「试抽当前文件」：只抽当前预览的文件，弹窗显示结果，
     用于检查字段位置是否正确（不影响批量结果）。
  4. 点「批量抽取」。结果显示在下方多个标签页中，可直接编辑。
     抽取过程中可点进度条右侧的「取消」；当前文件处理完后停止，
     已抽到的结果不会写入汇总区。
  4. 结果表编辑（与 Excel 操作习惯一致）：
       · 复制 Ctrl+C / 粘贴 Ctrl+V（TSV 格式，可直接和 Excel 互贴）；
       · 撤销 Ctrl+Z / 重做 Ctrl+Y（或 Ctrl+Shift+Z）；
       · Delete 清除选中单元格内容；
       · 右键菜单：插入行 / 删除行（选中多行可一次删）。
     插入或删除行后，「序号」列会自动重排。
  5. 导出：
       · 导出 xlsx：一张结果表写成一个 sheet；
       · 导出 csv ：一张结果表写成一个 csv 文件
         （UTF-8 带 BOM，Excel 可直接打开）。

  汇总结果的第一列固定为「序号」。
  若多个字段指向同一个取值单元格，保存模板或抽取前会弹窗提醒。


------------------------------------------
六、反向写入（汇总 → 分表）
------------------------------------------

  把汇总表每一行的值，写回对应源文件的字段位置，另存到输出目录。

  1. 先完成抽取；或在对话框中选择「导入汇总 Excel」。
  2. 点「反向写入」，选择汇总来源、结果表、目标模板表、输出目录。
  3. 选择「匹配字段」：工具读取每个分表中这些字段的值，再到汇总表中
     查找「全部相同」的那一行，把该行的汇总值回填进去。
  4. 执行前会先「预演」：读取并匹配所有分表（不写盘），弹窗显示
     「将写入 N 个文件 / M 个单元格」以及未匹配、错误数量，确认后才写。
  5. 完成后不弹窗：逐文件结果（已写入 / 未匹配 / 错误）写入下方日志，
     状态栏和日志末尾显示汇总计数（含未使用的汇总行）。

  重要：
  · 反向写入只处理 Excel 文件（.xlsx / .xls / .xlsm）。勾选里混有
    Word / PDF / CSV 时会自动跳过，并在日志中列出。
  · 若在字段映射中设了「主键」，匹配字段默认只勾主键；
    未设主键时，默认只勾「未被改动」的列——你改过的列已与分表旧值
    不同，参与匹配会导致一条也匹配不上。
  · 结果另存到输出目录，不会覆盖源文件。
  · 回填的单元格设为水平居中，其余格式保持原样。


------------------------------------------
七、模板
------------------------------------------

  模板保存「结果表 + 字段映射 + 主键」等整套配置，可反复使用。

  · 「打开模板」加载已有模板 JSON（默认定位到 data/templates）。
  · 「保存模板」弹出保存对话框，默认文件名和目录为
    data/templates/<模板名>.json，也可另存到任意位置。
  · 「管理」打开模板管理器：以表格列出 data/templates 下的所有模板，
    显示「模板名 / 最后修改 / 文件名」，按最后修改时间倒序（最新的在最上面，
    默认选中第一行）。可打开、重命名、复制、删除、刷新；
    也可从菜单「模板 → 模板管理器…」（Ctrl+T）进入。
    删除只删模板文件，不会删除已导出的数据。
  · 一个模板可包含多个结果表，一张结果表对应一个 sheet。


------------------------------------------
八、常见问题
------------------------------------------

  Q：抽取结果是空的？
  A：检查字段是否一个都没勾选，以及「sheet 关键字」是否匹配到 sheet。

  Q：扫描结果不全或有错？
  A：扫描只是建议。可试「AI 扫描表单」，或改值行/值列、手动配对补齐。

  Q：手动配对后取出的值不对？
  A：手动配对按位置读取，确认点击的是正确单元格。

  Q：AI 扫描报错或没反应？
  A：检查是否联网、Key 是否正确、API 地址和模型是否匹配、账户是否有额度。
     报错框会写明原因；可在「数据 → AI 接口设置（OpenAI 兼容）…」中检查。

  Q：扫描件 PDF 预览/抽取很慢或报错？
  A：没有文字层的扫描页会逐页调用视觉模型。请先在「数据 → AI 接口设置」
     里填「视觉模型」（如 gpt-4o、qwen-vl-max，需支持图片输入），并与
     普通模型共用同一个 Key 和 API 地址。每次预览/批量抽取都会重新识别，
     页数多时会比较慢；识别日志在 data/logs/pdf_vision.log。

  Q：Word/PDF/CSV 能反向写入吗？
  A：不能。反向写入只支持 Excel，其他格式会被跳过并记录到日志。

  Q：一个文件有多个 sheet 怎么一起抽？
  A：添加多个结果表，每张绑定一个 sheet；结果区多标签页，导出多 sheet。

  Q：预览只显示前 1000 行，抽取会漏吗？
  A：不会。预览只渲染前 1000 行，抽取会处理全部行。

  Q：想换深色/浅色主题？
  A：菜单「视图 → 深色主题 / 浅色主题」，选择会自动记住。

  Q：想换软件图标？
  A：菜单「视图 → 应用图标」，选择会自动记住。内置图标随程序打包
     （app/icons/，默认使用名为 1 的图标）。也可把自定义图标放到程序目录
     data/icons/ 下（png / ico / svg 均可）：同名会覆盖内置图标，
     不同名会追加到菜单里。


------------------------------------------
九、数据文件位置
------------------------------------------

  data/templates/        保存的模板（*.json）
  data/icons/            可选的自定义图标（覆盖/补充内置 app/icons）
  data/settings.json     AI 接口配置（Key/地址/模型）、主题、图标、窗口状态、
                        上次导入目录等本地设置（明文保存）
  data/logs/ai_scan.log  AI 扫描日志
  data/logs/pdf_vision.log  扫描件 PDF 的视觉模型识别日志

  打包为 exe 后，以上目录位于 exe 所在目录下。
  窗口大小、三栏宽度、上下分隔位置和上次导入目录会自动记住，
  下次启动自动恢复。


------------------------------------------
十、文件名正则速查（导入文件夹时使用）
------------------------------------------

  匹配规则：对「文件名（含扩展名）」做包含匹配，不检查文件夹路径。
  · 不区分大小写要用 (?i) 开头，默认区分大小写。
  · 不填 = 不筛选；写错会提示错误并禁用「确定」。
  · 先按正则筛出文件，再排序、再按「每个文件夹最多几个」截取，
    所以每组取的是「正则匹配到的文件里」排在前面（如最新的）那些。

  常见写法（以普通办公文件为例）：

  需求                                                         正则
  ---------------------------          -------------------------
  文件名含「销售」                                    销售
  「工资」或「薪酬」任一个                   工资|薪酬
  以 2024 开头                                          ^2024
  以「报告」结尾（xlsx）                       报告\.xlsx$
  2024 年任意月份（如 2024-03）       2024-\d{2}
  任意数字编号                                            \d+
  固定 4 位年份                                        20\d{2}
  年份 2023～2025                                 202[3-5]
  部门 A01～A12                               A(0[1-9]|1[0-2])
  忽略大小写（report/REPORT）            (?i)report
  排除带「副本」的文件                          ^(?!.*副本)
  只要 xlsx 文件                                         \.xlsx$
  「合同」后可带（终版/盖章版）      合同(终版|盖章版)?

  说明：
  · 匹配是「包含」关系，不必前后加 .*；只有 ^ 和 $ 才表示整名开头/结尾。
  · . 匹配任意字符，要匹配真正的点必须写成 \. （如 \.xlsx）。
  · (A|B) 表示 A 或 B；[0-9] 表示一个数字；A{2} 表示 A 连续出现 2 次。
  · 拿不准时边改边看预览列表，确认只剩想要的文件再点「确定」。
